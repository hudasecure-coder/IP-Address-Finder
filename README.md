# IP-Address-Validator

A simple Python project to validate an IP address and check whether it is public or private.

## Features

- Checks that the IP address consists of 4 parts.
- Verifies that each part contains only numbers.
- Ensures all numbers are between 0 and 255.
- Checks whether the given IP address is public or private.

## How to Use

Open the Python file in Google Colab (or any Python environment) and run it. You will be prompted to enter an IP address.

- How to check each part of an IP address using loops.
